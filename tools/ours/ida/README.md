# tools/ours/ida — headless IDA Pro 9.3 scripts for SLUS_216.21

All scripts run under the idalib venv python and must `import idapro` first. Run from the repo
root; pass paths as arguments (never `cd` into `extracted/`). The database `ida/p3fes.i64`
contains the game's bytes and is gitignored (`ida/`), as are `ida/logs/`.

```powershell
$PY = "deps\venv\idalib\Scripts\python.exe"      # this machine (CLAUDE.md); the old machine used C:\Users\Ash\.local\share\rea\ida-mcp
$ELF = "extracted\disc\SLUS_216.21"      # SHA-256 d1b163eb...3957bc (checked by open_p3fes.py)
```

Full rebuild from nothing (the sequence that round-trips, see "Round trip" below; ~3 min, most of it auto-analysis):

```powershell
& $PY tools\ours\ida\open_p3fes.py $ELF ida\p3fes.i64                                  # auto-analysis, 14,040 functions
& $PY tools\ours\ida\import_symbols.py ida\p3fes.i64 symbols\p3fes.sym --create-funcs  # names, promotions, FUNC_LIB, functions + chunks from function_chunks.txt
& $PY tools\ours\ida\create_funcs.py ida\p3fes.i64 tools\ours\ida\funcs_manual.txt      # all 31 already functions, 4 reported inside (as on the master)
& $PY tools\ours\ida\fix_code_items.py ida\p3fes.i64 tools\ours\ida\code_manual.txt     # 1,099 words already code
foreach ($t in "file_io","frame_loop_gs","irx_rpc_threads","vu1_gs") { & $PY tools\ours\ida\apply_types.py ida\p3fes.i64 symbols\types\$t.h symbols\types\$t.apply.txt }
& $PY tools\ours\ida\export_symbols.py ida\p3fes.i64 . --apply-names tools\ours\ida\names_manual.txt
git diff --stat symbols/   # only the `# generated` timestamp line of p3fes.sym
```

`tools/third_party/ps2sdk` must be present (`ps2_syscalls.py` reads its `syscallnr.h`; without it the 22 `_sce*` wrapper
names fall back to the PCSX2 table and differ). To compare two databases' exports instead, export each into its own
root (`export_symbols.py <db> <root> --elf $ELF --no-save`, `export_function_chunks.py`, `insn_census.py`,
`export_jumptables.py`) and run `roundtrip_diff.py <ref root> <new root>`.

Notes / gotchas verified on this machine:

* `idapro.open_database(file, run_auto_analysis, args)` honours `-p` and `-o`; the DB lands exactly at the `-o` path.
* The ELF loader with `-pr5900l` reports `inf_get_procname() == "r5900l"`, little-endian, base `0x00100000`, entry `0x00100008`.
* `ida_funcs.func_tail_iterator_t.first()` iterates *tails only*; use `idautils.Chunks()` for function sizes.
* `ida_bytes` has no `BADADDR`; use `ida_idaapi.BADADDR`.
* Hex-Rays (`hexmips.dll`) initialises for `r5900l` but emits `__asm` blocks for MMI/COP2/`syscall` (see `docs/ANALYSIS/04_decompiler_check.md`).
* Raw-opcode scans (`(w & 0xFC00003F) == 0x0C` for `syscall`) must be gated on `ida_bytes.is_code()` *and* function membership: IDA marks some VU-microcode/packet data as code (27 bogus `syscall` opcodes at e.g. `0x5e3240`, `0x5f93b0`).
* `ida_bytes.has_user_name()` is true for IDA's own `j_<target>` thunk names (they are regenerated when the target is renamed), so it cannot distinguish analyst names from derived ones; `import_symbols.has_user_name_at()` treats `sub_*`-style auto names and `j_*` as overwritable by hints.
* `ida_name.set_name()` fails on a non-head address (inside an existing data item); hints there are recorded as `mid_item` instead of splitting the item.
* `export_symbols.py` withholds unverified community hint names from every committed output: the function is exported as `sub_<ADDR>` in `p3fes.sym`/`functions.json`, D/L rows are dropped, and generated doc text is filtered at `write_doc` (listings and decompiler text embed callee names). Withheld rows go to `ida/logs/export_hints_withheld.txt`. Names from `names_manual.txt`, `verified` lines, and permissive sources (`fes-pc-recomp`, MIT) are exported with a `source=<src>` tag. The rule itself lives in `import_symbols.py` (`hint_status`, `withheld_name_map`, `export_disasm`); `export_function_chunks.py`, `export_jumptables.py` and `insn_census.py` write names and disassembly text through it too (functions → `sub_<EA>`, labels → `loc_<EA>`, data → `data_<EA>`, IDA comments dropped from disassembly text), so `function_chunks.txt`, `jumptables.json` and `insn_census.json` carry the same names as `functions.json`.

## Round trip: equal as of 2026-10-19 (`symbols/` is a complete text backup of the master)

database, reproduces the master's export: `roundtrip_diff.py` reports **0 differing rows** in `p3fes.sym` (15,398 rows:
