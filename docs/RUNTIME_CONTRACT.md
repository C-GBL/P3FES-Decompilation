# Runtime contract — what the Phase 3 runtime must emulate, by milestone

_Lead synthesis of the Phase 2 topic docs for the Phase 3 implementer (GOAL.md Phase 3; ADR-0004, -0008, -0010, -0011). Every number here is copied from a topic doc and carries its anchor; nothing was re-read from the ELF or an IDA database for this file. Where two docs disagree both are cited (§8.2). Confidence tags are the source doc's own: **obs** = observed in instructions/bytes, **der** = derived by script from observed data, **inf** = inferred, **unv** = unverified (needs the Phase 4 PCSX2 trace). Anchors: `10` = `docs/ANALYSIS/10_frame_loop_gs.md`, `11` = `11_file_io.md`, `12` = `12_irx_rpc_threads.md`, `13` = `13_overlays.md`, `14` = `14_vu1_gs_census.md`, `02` = `02_syscalls.md`, `06` = `06_ghidra_crosscheck.md`, `08` = `08_instruction_census.md`, `DL` = `docs/DISC_LAYOUT.md`._

Milestones (GOAL.md Phase 3): **M1** = recompiled binary reaches the first `sceGsSetDefDispEnv` / first frame flip; **M2** = Atlus logo; **M3** = title screen; **M4** = new game into the opening cutscene (out of scope here except where an M2/M3 item already covers it).

Item IDs: `B-` boot runway (M1), `L-` logo/title additions (M2/M3), `K-` kernel HLE, `I-` IOP HLE, `H-` hardware model, `V-` VU1, `S-` static-image assumptions, `Q-` open questions. Sections 3–7 are reference tables; the milestone that first needs each row is given in its `MS` column.
