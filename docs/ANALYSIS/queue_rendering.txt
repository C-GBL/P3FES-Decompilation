# Phase 5 rewrite queue -- rendering path (docs/ANALYSIS/22_rendering.md). Leaf-first by call depth on the SCC
# condensation of the render-path call graph (direct jal + function pointers stored by code + the Im2D dispatch tables).
# Columns: addr  name  size  class  depth  notes.  Names: the exported name (symbols/functions.json); a bracketed name is
# verified in 22_rendering.md and proposed in symbols/deltas/rendering.sym (not imported). Community hint names are not used.
# Class: a = pure builder (guest RAM / scratchpad writes only), a0 = builder that also uses di/ei/mfc0 Status (state in
# EEContext), b = touches hardware registers (EE 0x1000xxxx / GS 0x1200xxxx / VU control via cfc2-ctc2) -- address list in notes.
# Flags: c = hot on the per-frame path (c1 particles, c2 skin palette, c3 Im2D, c4 per mesh/atomic, c5 texture cache, c6 render
# state, c7 culling, c8 instancing (load time), c9 raster lock/blit); callsB = reaches a class-b callee (pair test: RecordingBus
# log + scratchpad + DMA buffer compare); vu0 = VU0 macro / lqc2-sqc2; spr = scratchpad base 0x70000000.
# Depth 0 = no callee on the path (jalr callbacks excepted).
#
