# Third-party notices

This project's own code is in `runtime/`, `recomp/`, `game/`, `tools/ours/`, `tests/` (except `tests/vendor/`). Everything below is third-party material that is **vendored or ported into the repository**; tools that are merely *fetched* into gitignored `tools/third_party/` are documented in `docs/TOOLS.md` instead and are not redistributed here.

Rule (ADR-0010 §2, ADR-0009 §3): every ported file carries a provenance line at its top (`// Ported from <repo> @ <commit>, <path>, <license>; adapted for p3fes-port`) and an entry in this file. GPL-licensed sources (`ran-j/PS2Recomp`, `god-of-war-recomp`, `p3fes-recompiled`, PCSX2) are never ported; community symbol maps without a license (`snaku/Persona3-FES-Decompilation`, TGE's PR #4) are consulted as private hints only and never committed.
